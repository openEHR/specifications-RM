=== EVALUATION Class

[cols="^1,3,5"]
|===
h|*Class*
2+^h|*EVALUATION*

h|*Description*
2+a|Entry type for evaluation statements. Used for all kinds of statements which evaluate other information, such as interpretations of observations, diagnoses, differential diagnoses, hypotheses, risk assessments, goals and plans. 

Should not be used for actionable statements such as medication orders - these are represented using the `INSTRUCTION` type.

h|*Inherit*
2+|`<<_care_entry_class,CARE_ENTRY>>`

h|*Attributes*
^h|*Signature*
^h|*Meaning*

h|*1..1*
|*data*: `link:/releases/RM/{rm_release}/data_structures.html#_item_structure_class[ITEM_STRUCTURE^]`
a|The data of this evaluation, in the form of a spatial data structure.

h|*0..1*
|*time_asserted*: `link:/releases/RM/{rm_release}/data_types.html#_dv_date_time_class[DV_DATE_TIME^]`
a|Time at which the content of this Evaluation was last asserted to be correct, i.e. when it was first recorded, or last updated or re-asserted. On first recording it is normally the same as the start time of the encounter (`COMPOSITION._context_._start_time_`), where the Composition has a context; it differs when one Evaluation in a Composition is updated or re-asserted and others are not, as in a persistent problem list or allergy list. 

This is the time of the statement, not a time in the clinical history of the subject: times such as when a diagnosis was made, time of onset or time of resolution remain archetyped values within `_data_`. It is also distinct from the time at which the Version containing the Evaluation was committed (`VERSION._commit_audit_._time_committed_`).
|===
