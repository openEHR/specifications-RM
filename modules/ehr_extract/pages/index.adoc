= EHR Extract Information Model [.spec-status.spec-status-trial]#{spec_status}#

Model for packaging and exchanging structured subsets of an EHR between systems, supporting query-driven extraction, synchronisation-based transfer, and discharge summary scenarios. The model supports both full and partial extracts, including the ability to filter by care episode, date range, archetype, or composition type. It is used in discharge summary exchange, patient summary transfer, and cross-institutional record sharing scenarios.

== Purpose

This document defines the openEHR Data Types This document describes the architecture of the openEHR EHR Extract Information Model. This model formally defines the concepts of ‘extract request’, ‘extract’, various kinds of content including openEHR and non-openEHR, and a message wrapper. It covers use cases including EHR system communication, other clinical content messaging, and EHR system synchronisation, as well as providing an equivalent of the ISO 13606 EHR Extract.

The intended audience includes:

* Standards bodies producing health informatics standards;
* Academic groups using openEHR;
* The open source healthcare community;
* Solution vendors;
* Medical informaticians and clinicians interested in health information.
* Health data managers.
