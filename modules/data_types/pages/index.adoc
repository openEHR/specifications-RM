= Data Types Information Model [.spec-status.spec-status-stable]#{spec_status}#

Complete set of clinical and administrative data types: quantities with units and precision, coded text, plain text, date and time representations, proportions, encapsulated media content, and URIs. The type hierarchy is designed to cover clinical documentation requirements without being domain-specific, enabling archetype authors to constrain them to particular use cases. Key types include DV_QUANTITY for measured values with units, DV_CODED_TEXT for terminology-bound concepts, and DV_DATE_TIME for temporal data.

== Purpose

This document defines the openEHR Data Types Information Model, used throughout the openEHR Reference Model.

The intended audience includes:

* Standards bodies producing health informatics standards;
* Academic groups using openEHR;
* The open source healthcare community;
* Solution vendors;
* Medical informaticians and clinicians interested in health information.
* Health data managers.
