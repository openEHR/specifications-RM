= {spec_title} [.spec-status.spec-status-stable]#{spec_status}#

Foundation package of the Reference Model. Defines assumed types, external terminology references, version identifiers, and measurement information shared by all other RM packages. It includes terminology-related definitions for referencing external terminologies such as SNOMED CT, LOINC, and openEHR's own terminology within RM instances. Implementers building any openEHR service layer will use the types defined here for version control, audit trails, and measurement unit handling.

== Purpose

This document describes the openEHR Support Information Model, whose semantics are used by all openEHR Reference Models.

The intended audience includes:

* Standards bodies producing health informatics standards;
* Academic groups using openEHR;
* The open source healthcare community;
* Solution vendors;
* Medical informaticians and clinicians interested in health information.
