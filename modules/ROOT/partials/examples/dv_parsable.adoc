A dosage instruction in HTML, to be parsed and rendered by the receiving system.

[tabs%sync]
======
Canonical JSON::
+
The usual form: the text, its formalism and its character set.
+
[source,json]
----
{
  "_type": "DV_PARSABLE",
  "value": "<p>Take <b>one tablet</b> twice daily with food.</p>",
  "formalism": "text/html",
  "charset": {
    "terminology_id": {
      "value": "IANA_character-sets"
    },
    "code_string": "UTF-8"
  }
}
----

All attributes::
+
Every attribute of `DV_PARSABLE`, including the optional ones inherited from `DV_ENCAPSULATED`.
+
[source,json]
----
{
  "_type": "DV_PARSABLE",
  "value": "<p>Take <b>one tablet</b> twice daily with food.</p>",
  "formalism": "text/html",
  "charset": {
    "terminology_id": {
      "value": "IANA_character-sets"
    },
    "code_string": "UTF-8"
  },
  "language": {
    "terminology_id": {
      "value": "ISO_639-1"
    },
    "code_string": "en"
  }
}
----

FLAT::
+
The same instruction in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME": "<p>Take <b>one tablet</b> twice daily with food.</p>",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|formalism": "text/html",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME/_charset|code": "UTF-8",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME/_charset|terminology": "IANA_character-sets"
}
----
