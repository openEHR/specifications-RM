A link to a patient information leaflet on the web.

[tabs%sync]
======
Canonical JSON::
+
The value is the only attribute.
+
[source,json]
----
{
  "_type": "DV_URI",
  "value": "https://www.example.org/leaflets/hypertension.html"
}
----

FLAT::
+
The same link in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME": "https://www.example.org/leaflets/hypertension.html"
}
----
