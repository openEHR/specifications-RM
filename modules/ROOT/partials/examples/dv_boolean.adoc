A yes/no answer, e.g. to _Current smoker?_.

[tabs%sync]
======
Canonical JSON::
+
The value is the only attribute.
+
[source,json]
----
{
  "_type": "DV_BOOLEAN",
  "value": true
}
----

FLAT::
+
The same answer in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME": true
}
----
