A reference to version 2 of a composition in a given EHR, using the `ehr:` scheme.

[tabs%sync]
======
Canonical JSON::
+
The value is the only attribute.
+
[source,json]
----
{
  "_type": "DV_EHR_URI",
  "value": "ehr:/7d44b88c-4199-4bad-97dc-d78268e01398/compositions/fb458d9c-1323-42bc-b7f8-787f3660a0b5::org.example.ehr1::2"
}
----

FLAT::
+
The same reference in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME": "ehr:/7d44b88c-4199-4bad-97dc-d78268e01398/compositions/fb458d9c-1323-42bc-b7f8-787f3660a0b5::org.example.ehr1::2"
}
----
