A PDF referral letter held externally and referenced by URI.

[tabs%sync]
======
Canonical JSON::
+
The usual form: a reference to the document, with its media type and size.
+
[source,json]
----
{
  "_type": "DV_MULTIMEDIA",
  "alternate_text": "Referral letter to cardiology",
  "uri": {
    "value": "https://records.example.org/documents/referral-0042.pdf"
  },
  "media_type": {
    "terminology_id": {
      "value": "IANA_media-types"
    },
    "code_string": "application/pdf"
  },
  "size": 245760
}
----

FLAT::
+
The same reference in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME": "https://records.example.org/documents/referral-0042.pdf",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|mediatype": "application/pdf",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|size": 245760,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|alternatetext": "Referral letter to cardiology"
}
----
