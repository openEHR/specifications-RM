The SNOMED CT term _Essential hypertension_, with a mapping to ICD-10.

[tabs%sync]
======
Canonical JSON::
+
The usual form: the term and its mapping.
+
[source,json]
----
{
  "_type": "DV_CODED_TEXT",
  "value": "Essential hypertension",
  "defining_code": {
    "terminology_id": {
      "value": "SNOMED-CT"
    },
    "code_string": "59621000"
  },
  "mappings": [
    {
      "match": "=",
      "target": {
        "terminology_id": {
          "value": "ICD10"
        },
        "code_string": "I10"
      }
    }
  ]
}
----

FLAT::
+
The same term in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|value": "Essential hypertension",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|code": "59621000",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|terminology": "SNOMED-CT",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME/_mapping:0|match": "=",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME/_mapping:0/target|terminology": "ICD10",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME/_mapping:0/target|code": "I10"
}
----
