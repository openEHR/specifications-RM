An oxygen saturation (SpO~2~) of 97 %, a percent proportion (`type` 2 = `pk_percent`, denominator 100).

[tabs%sync]
======
Canonical JSON::
+
The usual form: numerator, denominator, kind and precision.
+
[source,json]
----
{
  "_type": "DV_PROPORTION",
  "numerator": 97.0,
  "denominator": 100.0,
  "type": 2,
  "precision": 0
}
----

FLAT::
+
The same saturation in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|numerator": 97.0,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|denominator": 100.0,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|type": 2,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|precision": 0
}
----
