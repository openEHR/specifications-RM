A body temperature of 38.4 °C to one decimal place, flagged as above normal.

[tabs%sync]
======
Canonical JSON::
+
The usual form: magnitude, units, precision, display name and normal status.
+
[source,json]
----
{
  "_type": "DV_QUANTITY",
  "magnitude": 38.4,
  "units": "Cel",
  "precision": 1,
  "units_display_name": "°C",
  "normal_status": {
    "terminology_id": {
      "value": "openehr_normal_statuses"
    },
    "code_string": "H"
  }
}
----

FLAT::
+
The same temperature in the FLAT format. FLAT paths depend on the web template; `TEMPLATE_NAME`, `ARCHETYPE_NAME` and `ELEMENT_NAME` stand for the ids of a real web template.
+
[source,json]
----
{
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|magnitude": 38.4,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|unit": "Cel",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|precision": 1,
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|units_display_name": "°C",
  "TEMPLATE_NAME/ARCHETYPE_NAME/ELEMENT_NAME|normal_status": "H"
}
----
